# Reporter Workspace - User Guide

## 🎨 New Unified Workspace Design

The workspace has been completely redesigned to show **folders and reports together** in the main area, with flexible viewing options!

---

## 📋 Features

### 1. **Unified Grid/List View** 
- **Folders and reports** displayed together in the main workspace area
- **No sidebar** - cleaner, more spacious interface
- **Breadcrumb navigation** - see exactly where you are
- **Toggle between views** - Grid or List view with one click

---

## 🖼️ Grid View (Default)

### What You See:
- **Large folder icons** (📁) with folder name and report count
- **Report cards** (📊) with name, element count, and last updated date
- **Visual cards** in a responsive grid layout
- **Quick actions** below each card (Open/Edit and Delete)

### Perfect for:
- Visual browsing
- Quick identification
- Getting an overview at a glance
- Users who prefer visual navigation

---

## 📊 List View

### What You See:
A sortable, filterable table with columns:
- **Icon** - Folder (📁) or Report (📊)
- **Name** - Clickable name
- **Type** - Folder or Report (filterable)
- **Items/Elements** - Number of reports in folder or elements in report
- **Date Created** - When it was created
- **Date Updated** - Last modification time
- **Owner** - Who created it (currently shows "You")
- **Actions** - Quick action buttons

### Features:
- **Sortable columns** - Click column headers to sort
- **Type filter** - Show only folders or only reports
- **Pagination** - 20 items per page (adjustable)
- **Click anywhere on row** to open folder or edit report

### Perfect for:
- Power users
- Finding specific items quickly
- Sorting by date or name
- Detailed information at a glance
- Managing large numbers of items

---

## 🗂️ Navigation

### Breadcrumb Trail:
```
Workspace > Marketing Reports > Q4 Analysis
```
- Click any breadcrumb to navigate back
- Always see your current location
- Root level shows "Workspace"

### Folder Navigation:
1. **Click a folder** to open it
2. Breadcrumb updates to show path
3. See only reports inside that folder
4. Click "Workspace" breadcrumb to go back to root

---

## 🎯 Actions

### Top Bar:
- **📅 View Schedule** - Open schedule panel
- **➕ New Report** - Create a new report
- **➕ New Folder** - Create a new folder (only at root level)

### Item Actions:

**Folders:**
- **📂 Open** - Navigate into folder
- **🗑️ Delete** - Remove folder (warns if contains reports)

**Reports:**
- **✏️ Edit** - Open report builder
- **🗑️ Delete** - Remove report

---

## 💡 Workflow Examples

### Example 1: Organizing Reports
```
1. Start at Workspace (root level)
2. Click "➕ New Folder"
3. Name it "Sales Reports"
4. Click folder to open it
5. Inside folder, click "➕ New Report"
6. Build and save your report
7. Report is automatically in the folder
```

### Example 2: Finding a Report (List View)
```
1. Toggle to List View (☰)
2. Click "Date Updated" column to sort
3. Or filter by Type: "Report"
4. Or use browser search (Ctrl+F)
5. Click report name to edit
```

### Example 3: Moving Between Folders
```
1. Open "Sales Reports" folder
2. Breadcrumb shows: Workspace > Sales Reports
3. Create/edit reports in this folder
4. Click "Workspace" in breadcrumb to go back
5. All folders and root-level reports visible again
```

## 🚀 Quick Tips

1. **Use Grid View** for visual browsing and when you have few items
2. **Use List View** for sorting, filtering, and when you have many items
3. **Create folders** to organize reports by team, project, or time period
4. **Use breadcrumbs** to navigate quickly without losing context
5. **Double-click** items in list view to open them instantly
6. **Sort by "Date Updated"** in list view to find recently modified reports

---

## 📱 Responsive Design

The workspace automatically adjusts:
- **Desktop**: 4-6 cards per row in grid view
- **Tablet**: 2-3 cards per row
- **Mobile**: 1 card per row
- **List view**: Horizontal scroll on smaller screens
